The problem I actually hit

Build the same RISC Zero guest from a different directory and the image ID changes — even though the source is identical. Cargo embeds path-derived symbols in the ELF. An ID recorded on one machine is not a safe comparison value on another, and a wrong ID means you verify or call the wrong program.

🔍

proclaim-verify v1.0.0

A CLI that tells you the truth about the binary you actually have: real image-ID lookup via lgs, expected-ID comparison with CI-safe exit codes, base58 encoding, and canonical-path rebuild.

Shipped with a public battle-test kit and 11 recorded adversarial cases, including the first harness failure — kept, not hidden.
